# SoccerMatchTracking

• Technologies: Kotlin, Software Architecture, Git 
• Developed a comprehensive mobile soccer match tracking application utilizing Kotlin and native Android UI components for live score and league monitoring. 
• Designed a structured client-side UI hierarchy supporting multi-league match schedules, half-time scores, statistical indicators, and real-time search filtering. 
• Implemented interactive search event listeners, optimized scrollable layouts, and custom XML drawables to deliver an intuitive and responsive user experience.
